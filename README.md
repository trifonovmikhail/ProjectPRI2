# ProjectPRI2
Итоговый проект по дисциплине Программная инженерия
Выполнили: Трифонов М.В., Ахмедов В.Р., Терентьева Е.В. Проект: "Анализ текста на токсичность с использованием модели машинного обучения"
1. Склонируйте проект
2. Используйте подходящий скрипт для вашей системы:
  Для Windows:
    run.bat
   Для Linux/macOS:
     run.sh (Сделайте его исполняемым chmod +x run.sh)
Описание скрипта:
Создаёт виртуальное окружение .venv, если оно не существует
Активирует окружение
Устанавливает зависимости из requirements.txt
Запускает FastAPI-приложение на http://127.0.0.1:8000
